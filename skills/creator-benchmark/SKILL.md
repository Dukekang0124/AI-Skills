# 对标作品深度学习 (creator-benchmark)

## 何时用
用户丢来一个对标博主/作品的链接或 ID，想要「深入学习完整思路」「拆解」「打开思路」「这个作品为什么火」「以后我们也这么做」时。

## 目标
不是看完夸一句，是把一条作品拆到「能抄的照抄、会翻车的避开、立即落一个动作」，并把结论沉淀进学习库，可复用。

## 七步流程

### 0. 先查后做
- 查学习库是否已有该博主的拆解（README 索引 + grep 博主名）。
- 有 → 判断这条是「升级」（认知层次往上）还是「重复」（同层换标题），笔记里写清对照链。
- 无 → 新建，并在 README 索引加新博主。

### 1. 抓逐字稿（有链才有底）
- 优先用 `douyin-transcript` skill（抖音短链/ID → 完整逐字稿 `.txt`）。
- 抓不到逐字稿时，退级用「标题文案 + 金句 + 置顶评论」交叉还原，文末标注信源，不冒充逐字稿。
- 能抓互动数据（赞/藏/评/享）就抓，抓不到标注「待补」，**不虚构**。

### 2. 五结构拆解
逐字稿到手，拆五块（缺哪块标哪块——缺方法本体=收藏燃料不足，是扑街根因）：
- **反常识点**：戳破哪个流行共识？
- **钩子**：前三秒怎么留人（数字/悬念/断语/身份钩）？
- **金句**：可截图/可转发的原话，逐条列。
- **方法本体**：有没有「能带走的干货」（公式/清单/循环/步骤）？
- **结构**：段落推进逻辑（破→立→法→式→势 之类）。

### 3. 先判变现逻辑（能不能跟，铁律前置）
- 他卖什么？客单高低？这条在给他的人设/变现加什么戏？
- 跟自己卖的东西同不同？
- 不同 → 不能照搬话术包装，**只能抄结构，落点必须锚回自己的场景**。

### 4. 对照既有体系
- 这条是该博主的「升级再生产」还是「同层重复」？对比同类动作（反面教材：同一结论同层换标题三连扑）。

### 5. 可复用 / 不可复用（两列表）
- 能抄：结构 / 方法 / 流程（换自己的落点）。
- 不能抄：纯认知包装、宏大叙事、没有的身份背书、脱离自身场景。

### 6. 行动清单（必须落到可执行）
- 每条「能抄的」转成带 `- [ ]` 的具体动作，落到对应卡/库（选题红线卡、人机共创卡、审稿卡、选题库）。

### 7. 沉淀 + 索引
- 笔记进学习库，命名 `<日期>-<博主>-<主题>.md`。
- 更新学习库 README 索引（含「一句话核心」）。
- 提炼出可复用机制 → 走 skill-creator 固化进 SKILL 目录。

## 铁律
- 深度到极限：拆到第三层洞察，不是总结大意。
- 先判变现逻辑，再决定抄不抄。
- 锚回自身场景：脱离场景讲纯认知必翻车。
- 不虚构数据：抓到多少写多少，待补就标注。
- 结论沉淀，不做一次性感慨。
