# 封面流水线

## 功能
输入文章标题和核心观点，输出一套四平台封面（公众号/抖音/知乎/小红书）。

## 触发条件
- 用户要封面（公众号/抖音/知乎/小红书）
- 文章写完要配封面

## 使用步骤

### 1. 提炼一句话
问用户："这篇文章讲什么？" → 用一句话说清楚，作为封面主题。

### 2. 生成场景图
运行 `scripts/generate-cover-prompt.py` 生成生图提示词：
```bash
python3 scripts/generate-cover-prompt.py "文章标题" "核心观点" "动作"
```
将提示词交给 AI 生图模型，生成"人物在做这件事"的场景图。

### 3. 适配四平台
参考 `scripts/platform-sizes.json` 的尺寸：
| 平台 | 尺寸 |
|:--|:--|
| 公众号 | 900×383 |
| 抖音 | 900×1200 |
| 知乎 | 690×280 |
| 小红书 | 1242×1660 |

### 4. 自查
- 标题完整/清晰
- 人物形象一致
- 人物在做事（不站桩）
- 布局平衡/无畸形
- 整体专业感

### 5. 交付
导出四平台封面，交付用户。

## 依赖
- AI 生图模型 API（用户自行申请，通常有免费额度）
- Python 3（运行提示词脚本，可选）

## 注意事项
- 生成图需人工检查（AI 可能出畸形/文字错误）
- 封面质量取决于所选生图模型
- 不同平台审核规则不同，发布前自行确认合规
