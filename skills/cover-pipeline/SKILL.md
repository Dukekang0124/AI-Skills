# 封面流水线（Cover Pipeline）

> 把"做封面"这件事变成一条可复用的流水线：读文章→生成场景图→适配四平台→自查，30分钟搞定一套封面。

## 这个 Skill 帮你解决什么问题

做封面对很多人来说是"卡一下午"的事：找图、抠图、排版、调色，最后还不满意。

这个 Skill 把整个过程变成 5 个步骤，30 分钟完成一套四平台封面（公众号/抖音/知乎/小红书）。

核心思路：**封面不是"设计"，是"表达"——把文章核心观点翻译成一张图。**

## 触发条件
- 要给文章配封面（公众号/抖音/知乎/小红书）
- 文章写好了但封面卡住
- 想做固定形象的品牌封面

## 流程（五步）

### 1. 读文章，提炼一句话（5分钟）
- 问自己："这篇到底讲什么？" → 用一句话说清楚
- 写不出来？说明文章还没想清楚，先别做封面

### 2. 生成场景图（10分钟）
- 用 `scripts/generate-cover-prompt.py` 生成生图提示词（输入文章标题+核心观点+动作）
- 用 AI 生图模型 + 参考图，生成"这个形象在做这件事"的场景图
- 人物要"在做事"（比如文章讲"别等学会"→人物在电脑前干活），不是站桩

### 3. 加标题，适配四平台（15分钟）
- 尺寸参考 `scripts/platform-sizes.json`
| 平台 | 尺寸 | 布局 |
|:--|:--|:--|
| 公众号 | 900×383 | 横版，标题右侧 |
| 抖音 | 900×1200 | 竖版，标题上方 |
| 知乎 | 690×280 | 横版，标题右侧 |
| 小红书 | 1242×1660 | 竖版，标题上方1/3 |

### 4. 视觉自查（5项）
- 标题完整/清晰/可读
- 人物形象一致（不漂移）
- 人物在"做事"（不站桩）
- 布局平衡/无遮挡/无畸形
- 整体专业感

### 5. 交付+发布
- 导出四平台封面 → 发布 → 归档

## 包含的脚本
- `scripts/generate-cover-prompt.py`：封面提示词生成器（输入文章信息→输出生图提示词+平台尺寸+自查清单）
- `scripts/platform-sizes.json`：四平台尺寸配置
- `scripts/character.txt`：固定形象描述（可替换成你自己的形象）

## 使用前需要准备

**本 Skill 需要以下外部条件：**
1. **AI 生图能力**：需要一个 AI 生图模型（可自行申请相关 API 服务，通常有免费额度）——本 Skill 不内置生图模型，需用户自行申请并遵守该服务条款
2. **固定参考图**：建议准备一张你自己的形象图（卡通/真人皆可），用于保持角色一致（如无可使用内置默认形象描述）
3. **Python 环境**：运行提示词生成脚本需要 Python 3（可选，不用脚本也能手动执行流程）

**注意事项：**
- 封面质量取决于所选生图模型（免费模型角色一致性弱，付费模型更强）
- 生成图需自查（AI 可能出畸形/文字错误——发布前必须人工看一遍）
- 不同平台审核规则不同，发布前请自行确认合规

## 快速开始
1. 准备：生图 API + 一张形象参考图
2. 运行：`python3 scripts/generate-cover-prompt.py "文章标题" "一句话核心观点" "动作"`
3. 用生成的提示词去 AI 生图
4. 加标题适配四平台尺寸（参考 platform-sizes.json）
5. 自查 5 项 → 发布
