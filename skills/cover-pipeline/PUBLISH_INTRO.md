# 封面流水线（Cover Pipeline）

## 这个 Skill 解决什么问题

做封面对很多人来说是"卡一下午"的事：找图、抠图、排版、调色，最后还不满意。

这个 Skill 把整个流程变成 5 个步骤，30 分钟完成一套四平台封面（公众号/抖音/知乎/小红书）。

核心思路：**封面不是"设计"，是"表达"——把文章核心观点翻译成一张图。**

## 怎么用

1. 给文章配封面时，告诉 AI "用封面流水线给这篇文章做封面"
2. AI 会按 5 步流程执行：读文章提炼一句话 → 生成场景图 → 加标题适配四平台 → 视觉自查 → 交付
3. 输出：四平台封面（公众号 900×383 / 抖音 900×1200 / 知乎 690×280 / 小红书 1242×1660）

## 触发方式

- "帮这篇文章做封面"
- "要封面"
- "文章配封面"

## 需要准备

- 一个 AI 生图模型（可自行申请 API 服务，通常有免费额度）
- 一张你自己的形象参考图（可选，用于保持角色一致）
- 能运行 HTML 的本地环境（普通浏览器即可，不需要会编程）
