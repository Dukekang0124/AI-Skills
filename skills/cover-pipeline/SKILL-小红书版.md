# 封面流水线（Cover Pipeline）

> 把"做封面"这件事变成一条可复用的流水线：文章→AI生图→四平台适配→自查，30分钟搞定一套封面。

## 触发条件
- 要给文章配封面（公众号/抖音/知乎/小红书）
- 文章写好了但封面卡住
- 想做固定形象的品牌封面

## 流程（五步）

### 1. 读文章，提炼一句话（5分钟）
- 问自己："这篇到底讲什么？" → 用一句话说清楚
- 写不出来？说明文章还没想清楚，先别做封面
- **核心认知：封面不是"设计"，是"表达"——把文章核心观点翻译成一张图**

### 2. AI生成场景图（10分钟）
- 用AI生图模型 + 参考图（你的固定形象），生成"这个形象在做这件事"的场景图
- 人物要"在做事"（比如文章讲"别等学会"→人物在电脑前干活），不是站桩
- 示例提示词：`保持参考图中卡通人物完全一致的样貌，生成他在[动作+场景]`

### 3. 加标题，适配四平台（15分钟）
| 平台 | 尺寸 | 布局 |
|:--|:--|:--|
| 公众号 | 900×383 | 横版，标题右侧 |
| 抖音 | 900×1200 | 竖版，标题上方 |
| 知乎 | 690×280 | 横版，标题右侧 |
| 小红书 | 1242×1660 | 竖版，标题上方1/3 |

### 4. 视觉自查（5项）
- 标题完整/清晰/可读
- 人物形象一致（不漂移）
- 人物在"做事"（不站桩）
- 布局平衡/无遮挡/无畸形
- 整体专业感

### 5. 交付+发布
- 导出四平台封面 → 发布 → 归档

## 依赖与限制（必读）

**本 Skill 需要以下外部条件：**
1. **AI生图API**：需要一个生图模型（如豆包Seedream/通义万相等），需自行申请API key（有免费额度）
2. **固定参考图**：建议准备一张你自己的形象图（卡通/真人皆可），用于角色一致性
3. **HTML合成环境**：需要能运行HTML（本地浏览器即可，非必需会编程）

**适用限制：**
- 封面质量取决于所选生图模型（免费模型角色一致性弱，付费模型强）
- 生成图需自查（AI可能出畸形/文字错误——必须人工看一遍）
- 不同平台审核规则不同，发布前请自行确认合规

## 快速开始
1. 准备：生图API key + 一张形象参考图
2. 读文章提炼一句话
3. 用AI生成场景图（提示词含形象描述+动作）
4. 加标题适配四平台尺寸
5. 自查5项 → 发布
