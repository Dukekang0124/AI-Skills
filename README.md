# AI-Skills

> 把"我用AI做事的经验"沉淀成可复用的技能，分享给同样想用AI提升效率的人。
> Turn my hands-on AI experience into reusable skills, shared with anyone who wants to work smarter with AI.

## 这是什么 / What is this

我（一个AI深度使用者）在真实工作中，把高频重复的任务沉淀成了一套套"技能"（Skills）——每个技能是一个 SKILL.md 文件，描述**遇到什么场景→用什么方法→怎么一步步做**。

这些不是"别人教的理论"，是我**实际踩坑后总结的流程**。分享出来，你感兴趣可以直接用、可以改、可以拿去迭代。

---

I'm a practitioner who uses AI in real work. I turn high-frequency, repetitive tasks into reusable **Skills** — each one is a `SKILL.md` file describing **when to use → how to do it → step-by-step**.

These aren't theories from someone else — they're **proven workflows from real trial and error**. Take them, adapt them, iterate on them.

## 怎么用 / How to use

1. 看 README 或 `skills/` 目录，找到你感兴趣的场景 / Browse the README or `skills/` to find a scenario you care about
2. 读对应的 `SKILL.md`，里面有完整的触发条件、步骤、踩坑记录 / Read the `SKILL.md` — it has trigger conditions, steps, and pitfalls
3. 把它变成你自己的（复制、改写、迭代）——AI时代，经验分享就是最好的学习 / Make it yours — copy, adapt, iterate. In the AI age, sharing experience is the best way to learn

## 理念 / Philosophy

**AI不是帮你做，是帮你长出能力。**
每次解决一个问题，把它沉淀成可复用的流程——一次做对，终身复用。

**AI doesn't do it for you — it helps you grow the ability.**
Every time you solve a problem, distill it into a reusable process. Do it once, reuse it forever.
